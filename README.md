Random Task Generator — генератор случайных задач
Автор: Магомедов Рамазан Русланович
Дата: 01.05.2026

Описание проекта
Random Task Generator — это графическое приложение на Python для генерации случайных задач из предопределённого списка или добавленных пользователем. Программа сохраняет историю сгенерированных задач с временной меткой и позволяет фильтровать их по категориям: учёба, спорт, работа.

Возможности
Генерация случайной задачи по нажатию кнопки.
Добавление собственных задач с выбором категории.
Валидация ввода: нельзя добавить пустую задачу.
История сгенерированных задач с датой и категорией.
Фильтрация истории по категориям (учёба/спорт/работа/все).
Автоматическое сохранение и загрузка данных из tasks.json.
Интуитивно понятный интерфейс на Tkinter.

Требования
Python 3.7+
Библиотека Tkinder (входит в стандартную поставку Python).

Инструкция по запуску
1. Убедись, что установлен Python 3.7 или новее.
2. Склонируй репозиторий:
git clone https://github.com/[твой_логин]/random-task-generator.git
cd random-task-generator
3. Запусти приложение:
python main.py
4. Для работы с Git используй стандартные команды (git add ., git commit -m "...", git push).

Примеры использования
Добавить задачу: введи текст задачи и выбери категорию.
Сгенерировать задачу: нажми кнопку — появится случайная задача из списка.
Фильтровать историю: выбери категорию и нажми «Применить фильтр».
Данные сохраняются автоматически при генерации или добавлении задачи.
